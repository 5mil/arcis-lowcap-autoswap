# Arcis Lowcap Autoswap

Low-cap PoW coin wallet monitor, local RPC send (ARRR/FLO), and exchange autoswap system.

See Arcis_Lowcap_Autoswap_Manual.md for full technical reference.

## Quick start

```bash
python3 arcis_lowcap_autoswap.py   # self-test
python3 arcis_console.py           # console on :8080
```

Dry-run by default. Supported exchanges: NonKYC, XeggeX, AltQuick, TradeOgre, CoinEx.
